# MyBasket-Android-App

MyBasket is a shopping list item tracker android app developed in a team of 2 as part of a mobile software development project in third year. It was created with android studio using Kotlin and jetpack compose.

The app is created for and works on any android phone. The app allows a user to login or create an account. They can keep track of different shopping lists they have and any items they need to get or already have. They can also keep track of the quantity of an item they have already and set the expiry date which will show up in the calendar in the app. 

In this repo you can find the final design document which outlines the design process, all functionality in the app, the code behind it and provides images of it.
